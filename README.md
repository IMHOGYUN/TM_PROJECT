# 문체 DNA 분석 프로젝트

근현대 소설가의 문체를 정량화하고, 사용자의 글과 비교해 문학적 정체성을 분석하는 텍스트마이닝 프로젝트

---

## 팀 구성 및 역할

| 역할 | 담당 | 브랜치 |
|---|---|---|
| 데이터 수집 | 팀원 A | `feature/data-collection` |
| 전처리 | 팀원 B | `feature/preprocessing` |
| 피처 추출 + 모델링 | 팀원 C | `feature/feature-extraction`, `feature/modeling` |
| 평가 + 시각화 | 팀원 D | `feature/evaluation` |
| 서비스 구현 + 발표 | 팀원 E | `feature/service` |

---

## 프로젝트 구조

```
style_dna/
├── data/               # 작가별 txt 파일 폴더 (직접 추가)
│   ├── 이상/
│   │   ├── 날개.txt
│   │   └── 봉별기.txt
│   ├── 김유정/
│   └── ...
├── output/             # 결과 저장 (자동 생성)
│   ├── dendrogram.png
│   ├── stat_heatmap.png
│   └── summary.json
├── pipeline.py         # 메인 파이프라인
├── requirements.txt
└── README.md
```

---

## 분석 파이프라인

```
txt 파일 로딩
    ↓
전처리 (Kiwi 형태소 분석, 불용어 제거, 청크 분할)
    ↓
피처 추출
  ├── TF-IDF (어휘 벡터)
  ├── Word2Vec 평균 벡터 (의미 벡터)
  └── 통계 피처 7종 (문장 구조)
    ↓
벡터 결합 (정규화 후 concat)
    ↓
Ward 계층적 클러스터링
    ↓
시각화 (덴드로그램, 히트맵)
    ↓
사용자 글 분류
```

---

## 통계 피처 7종

| 피처 | 설명 |
|---|---|
| 평균 문장 길이 | 문장 하나의 평균 어절 수 |
| 단문 비율 | 10어절 미만 문장의 비율 |
| 어휘 다양성 (TTR) | 전체 토큰 대비 고유 단어 비율 |
| 수식어 밀도 | 형용사 + 부사의 비율 |
| 대화문 비율 | 따옴표 포함 문장의 비율 |
| 문장 길이 표준편차 | 문장 길이의 불규칙성 |
| 명사 비율 | 전체 형태소 대비 명사 비율 |

## 설치 및 실행

```bash
# 패키지 설치
pip install -r requirements.txt

# data/ 폴더에 작가별 txt 파일 추가 후 실행
python pipeline.py
```

데이터 없이 실행하면 샘플 데이터로 동작 확인 가능
